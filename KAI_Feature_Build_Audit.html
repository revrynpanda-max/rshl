Issues Found

  • Corrupted runtime state (resolved). data/kai-state.json and data/kai-mind.json were truncated/unparseable on disk before this session (classic sign of a crash mid-write, or a bad sync). KAI logged the parse failure, started from empty state, and the smoke test re-saved valid files — they are healthy now. These files are .gitignore'd, so the prior contents were not recoverable, but nothing parseable was lost.
  • Native node modules are Windows-built. tools/oracle-discord/node_modules/better-sqlite3 contains a Windows .node binary. It works on your PC but can't be exercised in a Linux sandbox, so the SQLite-backed modules (epistemic vault, dream engine, radio DJ) could only be syntax-checked, not run, here.
  • Naming drift between the list and the code. A few list items use marketing names that differ from the source: "DAVE Protocol" is Discord's real DAVE audio-encryption handshake (not "Decrypted Audio Voice Engine"); the 11th council agent is voice-specialist.js, not "Epistemic"; "Chyros/KAIROS" appears only in ARCHITECTURE_MANIFEST.md — its actual supervisor/heartbeat behaviour lives in ecosystem-manager.mjs + shared/sentinel.mjs under different names.
  • Stale duplicate files in src/. universe.rs.bak, main.rs.bak, oracle_server.rs.bak and similar backups are checked into the working tree. Harmless, but they clutter greps and the build folder.

What I Fixed vs. What I Recommend

Fixed during this session: the corrupted kai-state.json / kai-mind.json were regenerated as valid JSON by running the engine's own smoke-test save path. That's the only change made — I deliberately did not invent code for the few "missing" list items, because doing so would mean guessing at the intended design rather than fixing a real defect.

Recommended (your call — I can do any of these on request):

  • Harden src/persistence.rs: the fs::copy fallback (used only when fs::rename fails) is non-atomic and is the most likely original cause of the truncated state files. Replace it with a retry-on-rename or a fail-loud error.
  • Delete the *.rs.bak / *.bak files from src/ and src/bridge/ — git already has history.
  • Decide whether "Chyros/KAIROS", a named "Morning Briefing Protocol", and the full "STT Ghost Filter" should be (a) implemented for real or (b) removed from the architecture docs so the list matches the code.
  • Add a CI step that runs cargo check + kai --headless-smoke + node --check across the JS tree — all three pass today, so this would lock that in.
